## QA before importing to official web assets

- **Geometry:** source alignment/letterform ratio must be approved by the art director. Several candidate strokes are interpretations, not source-exact traced vectors.
- **Color:** the apparent black/silver/paper-white is observed, not certified colour spec; global green theme forbidden.
- **Fonts:** MOVA and Tea House original font files were not found in checked GitHub main trees. SVG fallback does not create the original font license.
- **Ownership:** neither historical sponsor footer nor nearby unknown marks become part of the team's reusable brand icon library.
- **Product status:** SpacePort navigation and station HTML are independent products with real route checks. A visual brand preview is not a verified operating station.
- **Release:** retain `candidate` suffix until SVG master/author permission, human visual comparison, 24/48 px legibility and 375/768/1440 browser screenshots pass. A passing CI syntax check is not aesthetic approval.
